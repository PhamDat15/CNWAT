Bảng Đối Soát Cơ Chế An Toàn Thực Hành (OWASP Web Security)

Nguy cơ tấn công Web Cơ chế phòng vệ đã triển khai Vị trí mã nguồn kiểm soát Trạng thái
SQL Injection (SQLi) Sử dụng 100% PDO Prepared Statements, tham số hóa toàn bộ đầu vào truy vấn core/Database.php • core/Model.php Đã ngăn chặn
Cross-Site Scripting (XSS) Bọc toàn bộ output qua htmlspecialchars(ENT_QUOTES) và CSP Headers core/Security.php::escape() Đã ngăn chặn
Cross-Site Request Forgery (CSRF) Tạo mã CSRF Token động theo Session, xác thực nghiêm ngặt mọi request POST/PUT Security::validateCsrfToken() • @csrf Đã ngăn chặn
Brute Force Login Bộ đếm Rate Limiting: Khóa tạm thời 5 phút nếu đăng nhập sai quá 5 lần Security::checkRateLimit() Đã ngăn chặn
Session Fixation & Hijacking session_regenerate_id(true) khi đăng nhập; kiểm tra dấu vân tay User-Agent Security::startSecureSession() Đã ngăn chặn
Remote Code Execution (RCE) Kiểm duyệt MIME type tệp tải lên; khóa thực thi script trong uploads/.htaccess Security::validateAndUploadImage() Đã ngăn chặn
